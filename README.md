# 연희 카레 팝업 초대장 🍛

모바일용 초대장 페이지입니다. 파일 하나(`index.html`)라서 빌드 없이 바로 열거나 GitHub Pages 같은 곳에 올리면 됩니다.

## 내용 수정
`index.html` 아래쪽 `<script>`의 `CONFIG` 객체만 고치면 됩니다: 날짜, 시간, 장소, 주소, 메뉴, 인사말, 호스트 연락처.

## 받는 사람 이름 넣기
링크 뒤에 `?to=이름`을 붙이면 봉투와 편지에 이름이 들어갑니다. 예: `.../index.html?to=민지`

## 인터랙션
- 봉투를 눌러 여는 인트로
- 카레 그릇을 눌러 저어 보기 (5번 저으면 완성)
- 오픈까지 남은 시간 카운트다운
- 네이버 지도 / 카카오맵 열기, 주소 복사, 캘린더(.ics) 추가
- 메뉴 카드 뒤집기 + ♥ 찜하기
- 맵기 레벨 슬라이더
- 참석 여부(RSVP) → 입장권 발급, 호스트에게 보내기(문자/공유/복사)
- 응원 메모, 초대장 공유하기

참고: RSVP와 메모는 보는 사람의 브라우저에만 저장됩니다. 호스트는 손님이 "호스트에게 보내기"로 보낸 메시지로 참석 정보를 받습니다.
